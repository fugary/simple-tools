# 国家介绍双语学习视频

只给国名即可开始。给定多个国家时每国独立成集。先在用户指定的工程或当前工作区查找 `国家介绍/`，如有则读取其中的 `AGENTS.md`、`默认配音.json` 和一个已完成篇目。新工程直接采用随技能携带的样式和声音。沿用本次要求及当前工程设置。已有同国工程时，核对稿件、音频和成片，复用仍匹配的材料。

1. **写一条能讲清楚的主线。** 从地图定位和首都切入，用一个孩子能回答的问题串起当地的地理、生活或文化。用官方地理、博物馆、世界遗产等来源核对名称、历史和比较范围。已有教材时保留学习目标，发现事实疑点先核实，同步修正正文与复习段。
2. **做成逐句双语稿。** 写入 `国家介绍/<国家>/<国家>介绍中英文学习稿.md`。顺序为双语片名与开场、主题讲解、互动问答、按主题复习的信息卡、系列结束语。省略课堂分组自报。新写国家介绍或从已有稿续做时，默认先使用同级[英语文章教学优化技能](../bilingual-article-teaching/SKILL.md)审稿，按六年级水平处理；用户指定其他年级时以该年级为准。每句英文配一句自然中文，选择完整搭配、意群或地理专名与中文对应高亮；易混项分条相邻对照，简短语法提示跟随原句，扩展例句按主题放入复习段。问答的答案应能从正文找到。片尾使用 “Thanks for exploring with us. See you next time!”。
3. **把稿件和画面接起来。** 按同级[视频清单格式](../teaching-slideshow-video/references/manifest.md)创建 `lesson.json`。将审定的双语条目直接作为 `cues`，保留 `highlight_en`、`highlight_zh` 和 `notes`。配音前把 `cues` 数组交给[教学标注核查脚本](../bilingual-article-teaching/scripts/study_cues.py)检查，再逐条复核它列出的高亮对应关系。按定稿后的条目顺序设置分镜与复习主题下标，首个分镜从 cue 0 开始。每个主题选一张对应实物、地点或生活场景的无字横图，正文和复习共用。记录图片来源，缺图时补教学插图并标明。核对地图位置和地标外形。封面与结束语用同一代表景观，答题停顿前避免用画面或字幕泄露答案。
4. **生成英文配音。** 逐句合成，仅朗读英文；年份、缩写、难读地名可用 `spoken` 指定读法。默认用同级教学视频技能的 `lesson_media.py narrate` 调用 Lily，模型参数和样音相对路径见[声音配置](../teaching-slideshow-video/assets/lily.json)。普通句停顿 2 秒，互动题在 cue 上单设 `pause: 3.5`。片尾措辞与默认音色匹配时，复制[系列结束语](assets/lily-outro.wav)到本集配音目录并写入最后一条 cue 的 `audio`。工程或用户指定了其他音色时按指定声音生成片尾。缺少指定模型或样音时，说明具体缺项并保留已完成稿件和分镜。
5. **按真实音频合成。** 使用同级[教学视频技能](../teaching-slideshow-video/SKILL.md)的 `lesson_media.py prepare` 生成时间轴，接着用 `build_subtitles.py` 调用[双语字幕技能](../bilingual-study-subtitles/SKILL.md)。准备本集 `复习主题.json`，在通用字幕生成后运行本技能的 `scripts/format_country_subtitles.py --build 成片工程 --review-topics 复习主题.json --ffmpeg FFmpeg路径`。它按本集时间轴生成双语封面、底部渐变、顶部学习提示和左侧复习标签。最后用 `lesson_media.py render` 烧录并交付 `成片工程/styled.ass`，导出 1080p 横屏 H.264/AAC MP4。命令参数见视频清单格式。
6. **验收与交付。** 检查完整解码结果、音画时长、逐句漏读与地名发音；从最终 MP4 抽查封面、地图、最长双语句、问答停顿、复习标签和结尾。交付可播放的 MP4、双语稿、ASS 和 SRT，注明实测时长。交付打印讲义时，按[打印版 Word 与 PDF](../bilingual-article-teaching/SKILL.md#打印版-word-与-pdf)导出同名 PDF 并核对分页。工程中保留清单、分镜、音频和时间轴。若项目使用统一的 `输出/` 目录，按现有编号和中英文国名归档，保留其他篇目。

复习主题文件内容形如 `[{"cue": 12, "topic": "River Valley"}]`。cue 是从 0 起的正文清单下标，按出现顺序填写，最后一条朗读留给结束语。时间取自本集时间轴。第一句英文按「国名 — 主题」拆成封面两行，中文作为第三行。复习标签固定在画面高度 22%。只有封面时传空数组文件。交付用最终 ASS 和基础步骤生成的 SRT。
