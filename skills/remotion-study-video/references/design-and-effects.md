# Remotion 动效设计与替代 `image-motion` 指南

本规范说明如何在**不扭曲实景照片像素、不产生网格噪点**的前提下，借助 Remotion 做出现代、克制、富有教学引导感的视频动画。

## 1. 为什么用以下 4 种方式替代 `image-motion`？

| 过去 `image-motion` 的问题 | Remotion 替代原语 | 适用场景 |
| :--- | :--- | :--- |
| 正弦/余弦波相乘产生的格子烟雾 | **实拍黑底 Screen 叠化**（`<OffthreadVideo>` + `mixBlendMode: "screen"` + 径向柔边遮罩） | 热气、飘雪、水雾、光束 |
| 整图水波/树叶扭曲导致船只楼房像果冻 | **底图 100% 锁定 + SVG 微粒/光斑**（`vfx.kind = "motes"`） | 阳光空气感、户外静景 |
| 全图机械推进导致眩晕与大楼弯曲 | **局部聚光聚焦（Spotlight）** + **平滑转场（`@remotion/transitions`）** | 讲解画中某样事物、切换知识点 |
| 手写 Canvas HUD 难维护、易与字幕撞车 | **React 磨砂玻璃 HUD 组件**（`spring()` 物理动画） | 海拔、面积排名、流向路线、国旗角标 |

## 2. 安全区与视觉层级规范（1920×1080）

画面自下而上分为四个互不遮挡的层级：

1. **Z1 底图实景层**：铺满 `1920×1080`（`objectFit: "cover"`），保持静定清晰；场景切换使用 `0.5s~0.8s` 的交叉溶解或轻柔滑动。
2. **Z2 氛围、纯正实景透亮与聚光层**：
   - **底图照片默认不做全屏暗衬（`backdropDim: 0`）**，仅保留极轻的边缘径向暗角（`rgba(7,10,18,0.22)`），让长城、山川、建筑处于 100% 透亮明晰状态；
   - **禁止与实景底图重复绘图**：当底图已经是长城、国旗或故宫实景时，不得在上方再叠加矢量长城、矢量国旗或遮挡建筑，也不得在实景上叠加持续旋转的空心线框地球仪干扰视觉；
   - `Spotlight` 仅压暗非重点区域（`dimOpacity` 建议 `0.32~0.42`），带 `<feGaussianBlur>` 柔边羽化与可选小标签；
   - 真实黑底视频素材必须加径向渐变遮罩（`maskImage: radial-gradient(...)`），防止出现方框边界。
3. **Z3 透亮 HUD 玻璃层、无框图解与垂直安全泳道**：
   - **大卡片避免 `blur()` 糊块**：大面积数据卡统一采用 `rgba(15, 23, 42, 0.42~0.48)` + `1.5px solid rgba(255,255,255,0.24)` 细边框 + 外阴影（**不对大卡片施加 `backdropFilter: blur(...)`**，以免把高细节山川/建筑背景糊成一片灰褐色）；仅在顶部紧凑小胶囊与语法解析条使用 `blur(20px)`；
   - **地形/剖面采用无外框全幅融入**：剖面曲线直接悬浮铺在风景摄影上（仅保留顶部轻量标题胶囊与随曲线落点的步进标签），不套笨重的矩形大外框；
   - **严格垂直泳道零碰撞**：章节胶囊固定 `top: 24px`（占 `y:24..72`），语法解析条居中 `top: 90px`（`#FF7B25` 关键词高亮），主体 HUD 数据卡统一下沉至 `y >= 228px`，彻底避免任何同框撞车；
   - **构图级图形叠加层（`GraphicOverlays`）**：与实景底图融合的数据卡、柱状图、书法圆印、无框三级阶梯剖面、8,849m 垂直标尺与长江流域进度轨（印章固定 `0°` 正向不旋转，严禁出现虚构经纬度）；
   - **角落轻量 HUD（`HudLayer`）**：`top-right` 等角落轻量卡片，当顶部语法提示存在时自动下避。
4. **Z4 底部字幕层（对齐 `bilingual-study-subtitles` 规范）**：
   - 底部 `260px` 柔和黑色线性暗部遮罩（`linear-gradient`）；
   - 英文在上（`52px` `#FFFFFF` + `4px #101820` 描边）、中文在下（`46px` `#FFBC00` + `3.5px #101820` 描边），左右留足 `80px` 安全边距；
   - `highlightEn` 与 `highlightZh` 统一使用活力橙 **`#FF7B25`** 精确高亮。

## 3. 如何准备真实黑底 VFX 素材（可选）

如果某一段落（如热气腾腾的饺子、茶杯）确实需要真实热气：
1. 准备一段 4~8 秒无缝循环的黑底白烟/热气 MP4（CC0 无版权素材）；
2. 放入 `remotion_studio/public/vfx/steam_loop.mp4`；
3. 在 `project.json` 对应场景中配置：
   ```json
   "vfx": {
     "kind": "screen_video",
     "videoFile": "vfx/steam_loop.mp4",
     "opacity": 0.5,
     "region": { "x": 0.50, "y": 0.48, "w": 0.34, "h": 0.40 }
   }
   ```
Remotion 会使用 `<OffthreadVideo>` 逐帧精确采样并自动循环播放，彻底消除 HTML5 `<video>` 异步 seek 导致的卡帧或黑帧。
