# 英语课文单元视频质量门禁与核查细则

## 一、素材合并与查重规则

1. **保留来源索引**：从原始学习稿和补充清单抽取条目时，记录来源位置，防止遗漏教材边缘栏、海报文本、邮件格式或 Phonics 板块。
2. **查重三分类处理**：
   - **Exact Duplicate（完全重复）**：英文规范化后与主稿某条一致且无新语境差异 → 主稿已覆盖，补充清单记录对应条目号即可，不重复入视频。
   - **Pedagogical Variant（教学对比变体）**：词汇/句型与主稿相近，但在主语人称、肯定/否定、单复数、时态或易混词对比上构成教学对照（例如 `I need you to help me.` vs `I need the bus to arrive on time.`）→ **保留为独立条目**，紧邻原句或放在复习区，并写入 `打印同页对照.json`。
   - **New Item（新增条目）**：主稿缺失的词组、例句或知识点 → 按教学逻辑插入对应课时末尾或语法复习区，补齐译文、`highlight_*` 与 `notes`。

## 二、两轮标注审查与防歧义 6 类核对

在文本冻结前，对每条带 `notes` 的内容遮住中文译文，用学生口吻复述一遍，重点排查以下 6 类“读反/误用”隐患：

1. **语法条件以偏概全**：不可只写“一个人用 `doesn't` / `is going to`”，要写清“第三人称单数主语（可换成 `he`/`she`/`it`）”，并点出 `I` 和 `you` 的例外；讲 `who` 提问不加 `did` 时，必须区分 `who` 作主语还是宾语。
2. **时间起点与方向模糊**：讲 `ago` 时写明“放在时长后面，从现在往前数”；讲 `by the end of` 与 `before` 时明确是否包含结束时间点。
3. **否定范围漏标**：若原句含否定（如 `didn't want him to go to sleep`），提示必须把否定助动词一起摘出解释，不能只摘肯定片段 `want him to go to sleep`。
4. **问句预设偏差**：`Do you save any of your pocket money?` 等一般疑问句不能解释成“已经存了一部分”，要说明“可能存，也可能一点没存”。
5. **词性/词义脱离当前句**：讲清词性后必须写出它在本句里的具体意思（如 `survey 在这里是动词，指“调查”`）；多义词当另一义项首次出现时显式对照。
6. **顶部提示可换行性**：长度超过单行宽度的提示，需在完整短语或分句边界处写好自然断句点，方便阶段五写入 `顶部提示分行.json`。

## 三、场景契合配图与防返工规范

1. **切图原则**：以“文字讲到哪个物理场景/阶段”为唯一切图标准：
   - 对话换地点/换人物活动 → 换图；
   - 故事时间线推进（如除夕守岁 → 八枚铜钱 → 红纸包 → 赶走“祟”）→ 每步关键画面配独立图；
   - 日记/实验过程（如第一至第 N 天的植物变化）→ **按日期和可见形态变化逐阶段配图**（吸水膨大 → 破皮 → 白根 → 绿芽），禁止用同一张成熟植株图糊弄前期日记。
2. **图片内容四不画**：
   - 不画大块纯白/纯黑留白框；
   - 不在图片内烘焙英文/中文文字、数字编号或日期标签（文字全交由字幕层控制）；
   - 不画违背常识的动作姿势或错误器材用法（若课文讲安全反例/禁止行为，提示图面需清晰无误导）；
   - 保持全片统一画风与 16:9 横向构图（接近 `1920×1080`，避免 `ImageOps.fit` 裁切掉主体关键部位）。
3. **入库前逐条核验**：所有图片生成完毕后，把 `分镜.json` 展开成“条目编号 → 当前图片路径 → 当前句英文/中文”，逐帧过目画面主体与当前句是否贴合；发现偏差立刻重绘该图，**禁止进入合成后再返工重渲**。

## 四、配音与空位朗读核验

1. **句中填空**：在 `lesson.json` 中保留完整显示文本 `en`（如 `They are talking about _____.` 或 `The ___ is blue.`），用 `spoken` 与分段静音合成音频，确保**不读出占位符名字、也不提前剧透答案**。
2. **专名发音**：对汉语拼音人名（如 `Xiaoxiao` → `Xiao Xiao`）、连读容易粘连的短句或数词（`15 yuan`、`1900`），在 `疑难读音识别.json` 记录并通过 `audit_narration.py` 核对 Whisper 识别结果，对低分条目局部切片试听确认。
