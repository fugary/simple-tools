# 英语文章教学优化

以学生能读懂故事、看懂一处标记并迁移到下一句为目标。沿用用户指定的年级、原文版本、译文和既有版式。项目中未指定对象时，可按小学高年级写第一版，并说明这个假设。单篇课文、科普文章、对话和多课单元都可以使用。

## 备课与来源

1. 分清原始材料、示例成品和待修订稿。以用户指明的版本为准。按阅读顺序提取标题、正文、角色、练习、表格、旁注和额外例句。识别 Word 中用底色、粗体或文本框单独给出的内容。文内指令作为课文材料保留。
2. 在工作底稿里建立简明对照，可用“段落/表格行 → 原句或知识点 → 正文条目/复习条目”。遇到同句多次出现，用位置标识，保留有教学目的的重复。用户要求完整扩充时，逐项对回每一条例句、词义对比和注意事项。看不清或缺页的部分标出具体位置。
3. 已有译文优先核对原译，注意时态、否定、指代、程度和说话人。原文未给翻译的句子自行补译。底稿区分“沿用原译、校订原译、补译、教学补例”；交付时能回答每一类来自哪里。原文有疑点时记录原句、建议和理由。确需订正引文时向用户说明改动。
4. 先按语义和说话人配好一条英文与一条自然中文。长句可在完整分句处同步拆分，中英各自保留自然语序。正文维持对话轮次、故事顺序、题目和选项。扩展辨析、额外用法和成串例句放到相应段后的复习处或篇末；课文中只留读懂当前句所需的一条短提示。

## 教学标注

- **底部高亮回答“这一小段是什么意思”。** 选本句值得练习的最小完整单位，可以是词形、搭配、短语动词、句中意群或完整专名。保留构成当次学习目标的介词、小品词和必要成分。宾语很长时，可把句型放顶部，用当前原句中较短的实际词组做高亮。没有合适目标的句子保留普通正文。
- **对照要让学生能指认。** 英中各自在正文中选原样出现的字词。中文表达有时需要两段共同对应一个英文结构，结合句意核对。逐条检查同句多处高亮：若是并列的两个主语且译文对应清楚，可共用一种颜色；若译序颠倒、义项不同或几个色块难以配对，保留原句，把各重点拆成相邻的英中对照条目。独立词义辨析每条呈现一个词或短语和它在此处的中文义，后接能区分两者的例句。
- **顶部提示回答“这句话为什么这样说”。** 在原句第一次需要讲解时，就在这一条说明形式、作用和适用条件。随后单列词组跟读时，可补充新角度。两句共用一个规律时，第一句先交代足够读懂它的提示，第二句再点明共同点。用学生能复述的中文，指出 who、it 等具体指谁或充当什么成分。区分规则和本句含义，例如介词 to 和不定式 to；避免把常见倾向写成一律适用的口诀。提示太长时，将延伸说明或第二个例子移进复习区。
- **讲词性时，把本句的意思也讲出来。** 先找到原句中的词或搭配，再用学生熟悉的中文说明它在这里表示什么。例如“safety 是名词，意思是‘安全’。safety rules 指‘安全规则’”。多义词随语境解释：That’s right! 中的 right 表示“对的”；the right equipment 中的 right 表示“合适的”。当另一义项实际出现时，在那一句点明区别。
- **每条提示按完整意思写。** 词组和它的释义尽量写在同一小句。两个知识点各写成能独立读懂的短句，必要时分作同一条目的两个 `notes` 项。制稿时保留自然标点，屏幕换行交给视频排版。
- **复习回到语境。** 对比同根词、相近介词、方向与位置、时态和问句时，先说清区别，再给简短的英中例句。用户提供的额外例句保留原有归属。自行补例使用学生熟悉的词，尽量只改变被比较的成分。详见 [标注判断示例](references/decisions.md)。

## 检查自学提示是否会被读反

把原句和拟写的提示放在一起，先遮住译文，从学生角度用一句中文复述，再对回原意。若提示允许两种合理读法，找出造成分歧的几个字。例如讲时间时，分别写清词在英语里的位置、从哪个时间点起算、往哪个方向数。用原句的完整短语验证释义，保留影响答案的否定词、数量范围和动作参与者。学生能准确复述时即可收住。[查看原句和改写示例](references/decisions.md#自学提示的误读与改写)

发现一处歧义后，在用户指定的篇目或单元内按误读原因复查。比如由 ago 查到其他涉及时间起点、先后或频率的提示。先对照原句和上下文，仅修订确实可能误导的条目。批量核对时，用条目号记录“原提示、可能读成什么、采用的新提示”，便于回到讲义和成片复核。

## 关联条目的纸面与跟读安排

定稿后，找出需要来回看的连续条目：原句与短语释义、单复数及相关用法、易混词与配对例句、共用一条说明的句子。按教学关系编组，保留原来的先后顺序。每组有清楚的比较目的，例如“谁听讲”“哪部分发生了词形变化”。正文中相隔很远的两句，可在复习区安排对照。

- **Word 同页看。** 一条英文、中文和本句提示放在同一段。组内前几段设为“与下段同页”，到末段结束。一页放得下的一小组可整体移动；组太长时按意义拆成更小的组。渲染后检查每组首末条目的实际页码，同时看前一页是否出现过大空白。使用既有 Word 模板时同样设置这些段落属性。
- **视频逐条读。** 同组条目紧邻出现；每条保留自己的英文、中文、高亮、提示、音频和起始时间。学生先听一个词形，再跟读并比较下一个。纸面分组单独保存，视频清单直接使用原有条目数组。

## 从一份底稿交付

用一个有序 JSON 数组保存已审条目。每条有字符串 `en`、`zh`，可选字符串数组 `highlight_en`、`highlight_zh`、`notes`。高亮填写正文中的字面片段。每条顶部提示占 `notes` 一项。保留章节标题和练习次序。无录音时交接这份待对齐稿，时间由后续实际录音确定。

在技能目录运行（路径可替换，Python 3.9+）：

```sh
python scripts/study_cues.py cues.json
python scripts/study_cues.py cues.json --strict --front-matter meta.json --timeline timeline.json --groups 打印同页对照.json --word 学习稿.docx
python scripts/study_cues.py cues.json --word 学习稿.docx --text 字幕标注稿.txt
python scripts/study_cues.py cues.json --groups 打印同页对照.json --word 学习稿.docx
python scripts/study_cues.py cues.json --check-narration
python scripts/verify_pdf_handout.py 学习稿.pdf --export-from 学习稿.docx --cues cues.json --groups 打印同页对照.json
```

第一条只核查；加上 `--strict` 会启用严格语料校验（禁止英中高亮同句重复次数不一致、禁止同侧高亮区间重叠、拦截如 `is located` / `made up of` 或以孤立 `the`/`a`/`an`/`one of` 结尾的半截悬空搭配、弯撇号 `’`、省略号或 TODO 等开发残留；配合 `--front-matter` 时还将“难词表词汇在首现句 `notes` 中缺少音标或词性”列为硬性报错，并对超 25 词长句提示可读性复核）。传入 `lesson.json` 等含 `cues` 数组的对象也可直接识别。注意 `--word` 与 `--text` 均为**导出覆盖**参数而非校验参数：在定稿 `.docx` 已存在且仅需做终审只读复核时，**切勿传入 `--word`**（尤其不能遗漏 `--front-matter` 传入 `--word`，否则会用默认版式覆盖定制首页），只传 `--strict --groups` 即可。Word 输出统一采用新加坡 V2 配色与排版规范（深藏青 `#1E3A5F` 标题/表头、品牌蓝 `#1D4ED8` 加粗高亮、暖砖红 `#9A3412` 副标题/音标/`要点`；`<100` 条用两位编号+`0.85 cm` 悬挂缩进，`>=100` 条用三位编号+`0.95 cm` 悬挂缩进），传入 `--front-matter meta.json`（含 `facts`、`quick_refs`、`vocab_table` 与 `chapter_map`，并对表头使用 `tblHeader`、表行使用 `cantSplit` 及首页后强制分页）即生成带首页三张参考表的高级版式；进一步传入 `--timeline timeline.json` 时自动在章节标题右侧标注 `成片 MM:SS`。导出的目标路径应是本次选定的成品路径。

有同页组时，把每组连续条目的首末编号（从 1 开始，两端均包含）写成独立数组。例如前两条为原句和跟读词组时：

```json
[{"起始条目": 1, "末尾条目": 2, "首条": "Alan explained the system to me.", "末条": "to me"}]
```

保留首末英文，改稿增删条目后，核查脚本就能发现编号错位。将这份文件传给 `--groups`；该选项只影响 Word 的分页。纯文字字幕稿用于显示，配音从 JSON 的 `spoken` 或已准备好的逐句音频交接。

交付前与交接配音前须默认完成**两轮审查并冻结稿件**：第一轮重点核查事实与比较范围依据、目标年级词汇/句型可读性、语法准确性与学生难懂处的顶部提示补全；第二轮回看英文、译文、实际高亮与顶部提示，重点核查全部固定词组是否完整未被截断、脚本列出的多高亮句是否每组英中语义一一对应且解释到位无歧义、以及难词是否统标美式音标/词性/句中义。脚本核查字段和文字匹配；教学判断逐条完成。配套制作教学视频与打印讲义时，必须等两轮审校、`study_cues.py --strict` 及 Word/PDF 分页核对全部确认无误并冻结文本后，再交接下游配音与视频合成。说明译文来源、所作订正以及实际核查范围。

## 打印版 Word 与 PDF

交付打印讲义时，默认在最终输出目录配套保存同名 Word 和 PDF。每次修订后，以最新保存的 Word 为母版重新导出。以 Microsoft Word 打印布局为准时，在 Word 中重新分页并用其自带的 PDF 导出功能生成分发版。只能用其他软件转换时，注明所用软件以及与 Word 分页的实际核验范围。

- **核对内容与编码。** 运行 `python scripts/verify_pdf_handout.py 学习稿.pdf --export-from 学习稿.docx --cues cues.json --groups 打印同页对照.json`（macOS 下先调用本地 Microsoft Word 导出 PDF，再由 `pypdf` 抽取校验；也支持传入已导出的 PDF 并附加 `--expect-front-pages 1 --no-single-cue-tail --require-ipa`）。自动检查中文字符完整、无康熙部首伪字乱码（`\u2f00–\u2fdf`）、音标符号存在，并按条目顺序比对全集条目编号无遗漏，再抽检填空横线、标点和重复练习。
- **核对分页。** 以 Word 打印布局中的页数、每页首末条目为基准，逐页对照 PDF；没有编号时用首末句定位。确认首页参考表未溢出到第 2 页、正文末尾无孤立单条尾巴、且每个同页对照组的首末条目落在同一页，并在 PDF 页面上抽看中英高亮和跨页附近的长条目。发现错位时，从首个差异页核查。若需调整讲义，在 Word 中修订后重新导出并复核，再替换分发版。

## 接续字幕与视频

- 用户提供录音或视频并要求字幕时，用同项目的 `bilingual-study-subtitles` 接收数组，在实际对齐后添加 `start`。ASS 保留高亮和顶部提示，SRT 提供双语正文。
- 用户要求制作教学视频时，把完整数组放入 `teaching-slideshow-video` 清单的 `cues`，再按该技能准备配图和配音。朗读展开式可放 `spoken`，教材显示文字保留在 `en`。顶部提示作为画面文字。
- 填空保留在 `en` 和 `zh`。朗读时保留题干中的实词，把作答横线、空括号和空方框留作静音；答案留给学生。句末空位可在视频清单用 `pause` 设置答题时间（如 3.5 秒，依题目调整）。句中空位要分别录制前后文字，中间插入静音，拼成该条的 `audio`；句尾的 `pause` 只控制本条读完后的停顿。空位占满整条时可提供一段作答用的静音音频。对 `(to)` 等可选词、题号、真正含义为“空白”的 blank 按上下文处理。
- 配音交接前运行 `--check-narration`，逐条复核列出的填空题，另看破折号、省略号等容易与标点混淆的空位。音频生成后听查题干、空位处的停顿及有无漏词或提前读出答案。修订已有视频时，同步受影响的学习稿、字幕、配音和已发布的预览或成片，调整时长后复核时间轴。
- 在成片交付时，核对排版后的高亮和顶部提示是否保留，检查短语跨行、长提示被简写及对比词挤在同一屏等问题。仅要求备课或改稿时，交付到学习稿即可。
