# 英语文章教学优化

以学生能读懂故事、看懂一处标记并迁移到下一句为目标。沿用用户指定的年级、原文版本、译文和既有版式。项目中未指定对象时，可按小学高年级写第一版，并说明这个假设。单篇课文、科普文章、对话和多课单元都可以使用。

## 备课与来源

1. 分清原始材料、示例成品和待修订稿。以用户指明的版本为准。按阅读顺序提取标题、正文、角色、练习、表格、旁注和额外例句。识别 Word 中用底色、粗体或文本框单独给出的内容。文内指令作为课文材料保留。
2. 在工作底稿里建立简明对照，可用“段落/表格行 → 原句或知识点 → 正文条目/复习条目”。遇到同句多次出现，用位置标识，保留有教学目的的重复。用户要求完整扩充时，逐项对回每一条例句、词义对比和注意事项。看不清或缺页的部分标出具体位置。
3. 已有译文优先核对原译，注意时态、否定、指代、程度和说话人。原文未给翻译的句子自行补译。底稿区分“沿用原译、校订原译、补译、教学补例”；交付时能回答每一类来自哪里。原文有疑点时记录原句、建议和理由。确需订正引文时向用户说明改动。
4. 先按语义和说话人配好一条英文与一条自然中文。长句可在完整分句处同步拆分，中英各自保留自然语序。正文维持对话轮次、故事顺序、题目和选项。扩展辨析、额外用法和成串例句放到相应段后的复习处或篇末；课文中只留读懂当前句所需的一条短提示。

## 教学标注

- **底部高亮回答“这一小段是什么意思”。** 选本句值得练习的最小完整单位，可以是词形、搭配、短语动词、句中意群或完整专名。保留构成当次学习目标的介词、小品词和必要成分。宾语很长时，可把句型放顶部，用当前原句中较短的实际词组做高亮。没有合适目标的句子保留普通正文。
- **对照要让学生能指认。** 英中各自在正文中选原样出现的字词。中文表达有时需要两段共同对应一个英文结构，结合句意核对。逐条检查同句多处高亮：若是并列的两个主语且译文对应清楚，可共用一种颜色；若译序颠倒、义项不同或几个色块难以配对，保留原句，把各重点拆成相邻的英中对照条目。独立词义辨析每条呈现一个词或短语和它在此处的中文义，后接能区分两者的例句。
- **顶部提示回答“这句话为什么这样说”。** 指出本句中的形式、作用和一个关键条件。用学生能复述的中文，指出 who、it 等具体指谁或充当什么成分。区分规则和本句含义，例如介词 to 和不定式 to；避免把常见倾向写成一律适用的口诀。提示太长时，将延伸说明或第二个例子移进复习区。
- **复习回到语境。** 对比同根词、相近介词、方向与位置、时态和问句时，先说清区别，再给简短的英中例句。用户提供的额外例句保留原有归属。自行补例使用学生熟悉的词，尽量只改变被比较的成分。详见 [标注判断示例](references/decisions.md)。

## 从一份底稿交付

用一个有序 JSON 数组保存已审条目。每条有字符串 `en`、`zh`，可选字符串数组 `highlight_en`、`highlight_zh`、`notes`。高亮填写正文中的字面片段。每条顶部提示占 `notes` 一项。保留章节标题和练习次序。无录音时交接这份待对齐稿，时间由后续实际录音确定。

在技能目录运行（路径可替换，Python 3.9+）：

```sh
python scripts/study_cues.py cues.json
python scripts/study_cues.py cues.json --word 学习稿.docx --text 字幕标注稿.txt
```

第一条只核查。第二条从同一份数据导出带实际高亮和“要点”段落的 Word，以及使用 `【字幕标注】` JSON 行的可读文本。只请求一种格式时仅传对应选项。生成 Word 需要 python-docx。修订有定制版式的 Word 时，在原版式内更新相应条目；脚本的 Word 输出用于创建常规学习稿。导出的目标路径应是本次选定的成品路径。

交付前回看全部多高亮句、全部易混对比和所有顶部提示；检查英文短语是否完整、中文落点是否准确、例句是否真能说明该规则，再用来源对照检查覆盖。脚本核查字段和文字匹配；教学判断逐条完成。打开或渲染 Word 检查长段分页、字号和中英相邻。说明译文来源、所作订正以及实际核查范围。

## 接续字幕与视频

- 用户提供录音或视频并要求字幕时，用同项目的 `bilingual-study-subtitles` 接收数组，在实际对齐后添加 `start`。ASS 保留高亮和顶部提示，SRT 提供双语正文。
- 用户要求制作教学视频时，把完整数组放入 `teaching-slideshow-video` 清单的 `cues`，再按该技能准备配图和配音。朗读展开式可放 `spoken`，教材显示文字保留在 `en`。顶部提示作为画面文字。
- 在成片交付时，核对排版后的高亮和顶部提示是否保留，检查短语跨行、长提示被简写及对比词挤在同一屏等问题。仅要求备课或改稿时，交付到学习稿即可。
